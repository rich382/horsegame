# 2026-08-17 — Meshy plugin

## What it is

The official **Meshy** Godot plugin (`addons/meshy-godot-plugin`, v0.1.6) is enabled. It is an editor bridge, not a runtime generator:

1. Meshy tab → **Run Meshy Bridge** (port 5325)
2. **Open Meshy Editor**
3. Generate a model on meshy.ai and import it
4. Files land in `res://imported_models/<name>/`

The plugin cannot be driven from headless Godot. Generation from this workspace uses the Meshy REST API (`tools/meshy_text_to_3d.py`) when `MESHY_API_KEY` is set. Meshy's published test-mode key only returns a sample wooden mug.

## Farm hook

`FarmYard` plants a Meshy mesh on the west drive if it finds:

- `assets/models/farm/truck.glb` / `trailer.glb`, or
- an `imported_models/` folder whose name contains `truck` / `pickup` / `trailer`

Otherwise it keeps the CSG stand-in so tests still see `TruckCab` / `TrailerBox`.
