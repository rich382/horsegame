# 2026-08-17 — AAA horse path

## Ask

The free zip / homemade rig is not good enough. Figure out AAA.

## Decision

You cannot generate a AAA horse. Buy a game-ready pack and drop it in.

Locked in [`docs/ART.md`](../ART.md):

- **Buy:** Horse Animset Pro ($75, Unity) → export `assets/models/horse/hero.glb`
- **Anatomy alt:** Horse Herd (Unreal)
- **Retarget later:** Auto-Rig Pro + ARP horse clips
- **Free step-up:** BlendSwap CC0 “Horse Rigged All Gaits” (login)
- Meshy = props only

`HorsePresenter` now prefers `hero.glb` when that file exists.
